# Personal preferences

## Responses

- Be concise and direct. Use short sentences and minimal tokens.
- Provide deeper detail only when asked.

## Documents

- Ask before generating a new file unless the user explicitly asked to create it.
- Use Markdown for documents unless the user explicitly requests another format.

## Japanese language

- Explain grammar with examples.
- Break down sentences in tables with furigana.
- Mention the relevant JLPT level.
- Assume the user's current level is N5–N4.
