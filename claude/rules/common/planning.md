# Planning

Default plan format in plan-mode:

1. Inspect
2. Design
3. Implement
4. Test
5. Verify

Each line:
<action> <target>

Formatting:

- Markdown bullets (`- `), not bare lines.
- Backtick every filename, type, identifier, command.
- Section with more than 3 unrelated items: group under a bold sub-label, blank line between groups.

Forbidden:

- paragraphs
- explanations
- repeated context
- "we will..."
- "next..."
- "this approach..."
- risk analysis
- success criteria
